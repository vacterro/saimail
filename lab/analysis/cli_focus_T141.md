# Compact focus through the CLI

T-140 made assessment age explicit but still transported a full cycle before
projecting its 1279-byte agent view. Its retained fresh-process measurement is
`.saipen/evidence/T-141-cli-focus/before-result.json`: both full cycle and client
focus cost 4791 normalized wire bytes, including contract negotiation.
Pre-change CLI/client/contract sources are retained alongside it.

T-141 adds an optional negotiated CLI operation over the existing keyless cycle.
It keeps one admission, context recheck and observation clock, then projects
metadata without private-key access or implicit review. The original full cycle
and default client focus remain available. `prefer_cli=True` selects compact
transport when supported, otherwise the original cycle projection. A refused
compact operation is not retried with another action.

The client independently checks compact metadata using its existing version-1
cycle validator. It rebuilds closed references, reasons and operations; no peer
command, body, suggestion or unknown coverage field is copied into the view.
An unbound Work still requires integer zero examination counts. Partial views
retain the same query and continuation; their local next operation is focus.

Replay version 4 preregisters four modes and three rotating-order repetitions
before starting a trial. `lab/out/CLI_FOCUS_T141/attempt-001/` passes 27 controls:

| Observation | CLI calls including negotiation | Normalized wire bytes | Agent-visible bytes |
| --- | ---: | ---: | ---: |
| Separate awareness + metrics | 3 | 4211 | 3077 |
| Full cycle | 2 | 4841 | 3707 |
| Original client focus | 2 | 4841 | 1279 |
| Preferred compact CLI focus | 2 | 2643 | 1279 |

Compact transport saves 45.4% of wire bytes compared with the same current full
cycle, without changing visible metadata or call count. The contract grows 50
bytes from the historical T-140 measurement; that earlier artifact is unchanged.
Timing remains descriptive, not a latency improvement claim.

`control.py` applies one fixed cost criterion to retained before and current
measurements. Before fails only the requirement that focus wire be below 75%
of cycle; after passes it. Both preserve discovery/temporal controls and the
two-call/1279-byte agent view. Hashes bind the same criterion, retained sources,
before measurement and current subject/measurement. This compares recorded
behavior and is not an independent receiver verdict.

`tests/test_cli_focus.py` checks real direct CLI use, lower transport cost,
original-view equivalence, fresh-process negotiation with an older peer,
unsupported optional versions, partial resume and changed context, no selected
Work, one admission, malformed compact metadata, ignored peer instructions,
strict count types and no fallback after a refusal. Existing host/cycle/focus
tests remain unchanged. The trials invoke no provider or external recipient;
scripted choices do not establish recurring field usefulness or agent comfort.
Those remain requirements of the active evolution objective.

Attempt 002 repeats the same 27 controls with identical byte measurements after
