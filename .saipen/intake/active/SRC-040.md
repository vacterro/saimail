======================================================================
SOURCE INTENT
======================================================================

B-012 is already captured as:

ALLY_ADVICE / PERSONAL REFLECTION

Normative backlog meaning:

- not an instruction
- not authority
- not evidence
- admissible only as context or explicit proposal

The source discussion further establishes the intended genre:

not psychologist
not coach
not boss
not admirer

but an ally who can say, approximately:

"I noticed a recurring pattern.
Here are the concrete cases.
Here is why it may matter.
Here is evidence that weakens my interpretation.
I may be wrong.
The decision remains yours."

Core invariants:

PERSONAL != FLATTERY
OBSERVATION != MOTIVE
INTERPRETATION != FACT
GUIDANCE != COMMAND

and:

Every unsolicited personal recommendation should carry the strongest available
evidence against its own interpretation.

The system must tolerate:

NO PERSONAL LETTER

for days or weeks.

Scarcity is expected.

----------------------------------------------------------------------
A2  ALLY_ADVICE IS NOT EVIDENCE
----------------------------------------------------------------------

The object may CITE evidence.

The object itself is not evidence.

The object may contain:

but they remain predecessor/agent assertions tied to cited references.

Preserve:

ALLY_ADVICE != FACT
ALLY_ADVICE != EVIDENCE
ALLY_ADVICE != AUTHORITY
ALLY_ADVICE != COMMAND
ALLY_ADVICE != KNOWLEDGE
ALLY_ADVICE != LEGACY
ALLY_ADVICE != SAIPEN TASK

Evidence references prove only:

what source was cited

unless a resolver separately proves existence.

Even resolved evidence does not mechanically prove that it supports the prose.

Preserve:

REFERENCE_EXISTS != REFERENCE_SUPPORTS_CLAIM

----------------------------------------------------------------------
A4  OBSERVATION ITEMS
----------------------------------------------------------------------

OBSERVED is not one unstructured claim blob.

Use bounded immutable observation items.

A display renderer may separately show labels if supplied externally.

----------------------------------------------------------------------
A5  PATTERN FLOOR
----------------------------------------------------------------------

B-012 exists for repeated patterns, not one random incident being turned into a
theory about a person.

Use a conservative v0 structural eligibility floor:

MIN_OBSERVATIONS = 2

MIN_DISTINCT_OBSERVED_EVIDENCE_REFS = 3

Every observation:
>= 1 evidence ref

Evidence refs:
deduplicated canonically

This floor does NOT prove a real pattern.

It only prevents the canonical ALLY_ADVICE path from presenting a single
incident as sufficient pattern evidence.

Record:

STRUCTURAL_PATTERN_FLOOR != SEMANTIC_PATTERN_PROOF

----------------------------------------------------------------------
A6  COUNTEREVIDENCE IS REQUIRED
