----------------------------------------------------------------------
A5 — SELECTED INPUT VS CONTAINER
----------------------------------------------------------------------

For selected-section inputs:

the registered semantic input identity is:

EXTRACTED_SHA256

not the hash of unrelated bytes elsewhere in the same mutable container.

CONTAINER_SHA256_AT_REGISTRATION may remain evidence about the historical

must NOT invalidate historical input identity.

This specifically avoids repeating the DECISIONS.md coupling.

A6 — WHOLE FILE
----------------------------------------------------------------------

-> mismatch

  that NEW experiment

or another named fail-closed result.

0 on refusal.
