### P1-A  G13 can be forged by a two-field acceptance JSON

Production `cmd_gates` currently defines external success effectively as:

- `external.status == PASS`
- `external.candidate_sha256 == exact a3 SHA256`

It does not require the exact a3 acceptance schema, acceptance version, proof hash, exact candidate version, publication boundary, or critical admission checks.

Audit red control was executed against the real production gate driver with this synthetic file:

```json
{"status":"PASS","candidate_sha256":"6427feab24c310184e7fd3ec4bb33dc3f5b1581b00128e2ec08d456fa5aa10cc"}
```

Result from the real gate driver:

- status: PASS
- terminal: DONE

This is a verified false-positive release-control defect. A hand-written two-field JSON must never satisfy G13.
